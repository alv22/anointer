# ☨ Anointer

**A quick blessing for your typography choices.**

---

## The Gospel

Anointer is a bookmarklet that bestows upon thee the power to test any Google Font on any text, on any website. Select thy text, choose thy font, and witness the transubstantiation.

No installations. No configurations. No indulgences required.

---

## Receive the Gift

Visit **[anointer.hexagon.fi](https://anointer.hexagon.fi)** and drag the sacred button unto your bookmarks bar.

Or, if thou art a developer of the faith:

1. Clone this repository
2. Run `npm install` to gather the sacred dependencies
3. Run `npm run dev` to summon the development server
4. Drag the bookmarklet to your toolbar

---

## The Ritual

**I.** Journey to any website

**II.** Click the Anointer in thy bookmarks

**III.** Select the text thou wishest to transform

**IV.** Choose thy font from the holy dropdown

**V.** Adjust weight and size with the sacred sliders

---

## Features

- **100+ Google Fonts** at thy fingertips
- **Live preview** — changes apply instantly
- **Font weight slider** — 100 to 900, for the thin and the bold alike
- **Font size slider** — 50% to 200%, relative to the original
- **Keyboard navigation** — Arrow keys to browse, Enter to select
- **Font detection** — Recognizes the current font if it dwells within the list
- **On-demand loading** — Fonts load only when needed, preserving the sanctity of page performance

---

## The Sacred Scrolls (Development)

This temple is built upon **Vite** and **Tailwind CSS**. The bookmarklet dwelleth in `src/bookmarklet.js`, annotated with JSDoc scriptures for the edification of future disciples.

```bash
# Install the sacred dependencies
npm install

# Summon the development server (localhost:5173)
npm run dev

# Prepare the offering for production
npm run build

# Preview the production build
npm run preview
```

### The House of the Lord

```
src/
├── main.js           # Encodes the bookmarklet into a holy URL
├── bookmarklet.js    # The source of all font blessings
└── styles/
    ├── main.css      # Tailwind incantations
    └── decorations.css  # The ornamental crosses
```

Upon building, Vite shall minify the bookmarklet and place it at `dist/bookmarklet.js`, stripped of comments but not of its power.
